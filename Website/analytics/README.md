# Website analytics last file

`daily-last.json` is a copy of the newest Mainland analytics daily doc mirrored by `Logs/Website/analytics/pull-from-api.sh` or Pacific `Website/scripts/analytics_pull.py`.

Authoritative day files stay under `Logs/Website/analytics/daily/YYYY-MM-DD.json`. Reports prefer that path (then `analytics-last.json`).
